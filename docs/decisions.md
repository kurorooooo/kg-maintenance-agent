# 決定事項ログ

brainstorm.md の「未決事項」に対する決定。2026-10-04 確定。

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| Neo4j の稼働先 | ローカル Docker Compose（neo4j:5.26-community） | Aura Free は3日無操作で停止・30日で削除されるため、商談直前の消失リスクを避ける |
| 読み取り専用 | mcp-neo4j-cypher の読み取り専用モードで write ツールを無効化 | Community 版はロール作成（RBAC）が使えない。真の RBAC が必要なら Enterprise 評価版に差し替え |
| Claude 側の入口 | Claude Desktop（stdio）＋ Claude Code（.mcp.json） | Desktop はデモ本番用、Code は開発・検証用。claude.ai コネクタは HTTP 公開が必要なため次フェーズ |
| 埋め込みモデル | ローカル intfloat/multilingual-e5-small（384次元） | API キー不要、オンプレ訴求と整合。質問文の埋め込みは自作 MCP ツール search_manual が担う（Day 4） |
| 業種設定 | 汎用。ライン1 プレス、ライン2 搬送コンベア、ライン3 冷却ユーティリティ | 各ラインに同型冷却ポンプ（CP-200）を置き、質問2「別ラインの同型機」を成立させる |
| 可視化 | Neo4j Browser | Bloom は Community 版で不可。NeoDash は余力があれば |
| 命名 | ラベル・プロパティ・リレーションは英語、値は日本語 | Cypher 生成の安定性と、国内製造業への「自分事化」の両立 |
| グラフモデル | 12ノード。資格は Procedure/Technician の属性、手順書出典は Chunk の属性 | docs/model.md 参照 |

## brainstorm.md からの修正点

- 「MVP では read_cypher から db.index.vector.queryNodes を直接呼ぶ」は成立しない（Claude は質問文のベクトルを作れない）。search_manual ツールを Day 4 に前倒しする。
- 「読み取り専用ロール」は MCP 側の読み取り専用モードで代替する。

## 2026-10-04 追記（E2E 実測後）

| 項目 | 決定・提案 | 理由 |
| --- | --- | --- |
| 応答時間目標 | 10秒 → 30秒以内に見直しを提案 | 初回 E2E で 4 問とも正答だが 37〜71 秒。ツール呼び出し 4 回と長文出力が主因。プロンプト簡潔化とモデル先読みで短縮を図る |
| 回答の長さ | 400〜700字、表は1つまで | デモ中に読み切れる量に抑える。聞かれていない提案（先行発注等）は書かない |
| デモで使うモデル | 未決。Opus 系（Q1 約55秒、フォーマット遵守良好）か Sonnet（Q1 約21秒、フォーマットやや緩い） | リハーサルで両方を試し、商談の性質で決める |
| Claude Desktop の使い方 | プロジェクトではなく通常チャットで、システムプロンプトを最初の発言として貼る | プロジェクト内チャットにはローカル MCP ツールが渡らないことを確認（ログに tools/call なし、通常チャットでは届く） |
