# 1. 概要

BC-50 はヘッド側に 2.2kW 駆動モーターと 1/30 減速機を備え、幅 500mm のベルトをヘッドプーリーとテールプーリーで駆動する。テールプーリーは深溝玉軸受 6306ZZ で支持され、張力はスクリューテンショナで調整する。搬出端に反射型光電センサを備える。

# 2. 日常点検

## 2.1 異音・振動

テールプーリー部からの連続的なうなり音や周期的な打音は、テールプーリーベアリングの固着やグリース切れの兆候である。粉塵の多い区画ではシール部からの粉塵侵入により固着が早まるため、点検周期を短縮する。

## 2.2 ベルトの蛇行

ベルトがプーリー端から 10mm 以上片寄る場合はテンショナで張力を左右均等に調整する。調整で収まらない場合はベルトの片伸びを疑い交換する。

## 2.3 過電流

駆動モーターの電流値が定格の 110% を超える場合はキャリアローラの固着、テールプーリーベアリングの固着、減速機の歯面摩耗を順に確認する。

# 3. テールプーリーベアリングの交換

標準交換周期は 24 か月。異音、過電流、軸受部の温度上昇（周囲＋40℃超）があれば周期前でも交換する。

1. コンベアを停止し電源を遮断する。
2. テンショナを緩めてベルト張力を抜く。
3. 軸受ユニットのボルトを外し、テールプーリーを取り外す。
4. 軸受 6306ZZ を交換し、グリース EP2 を充填する。
5. テールプーリーを復旧し、張力を再調整する。
6. 試運転でベルト蛇行と異音の有無を確認する。

所要時間 3 時間。回転機械整備の資格を要する。粉塵区画では防塵カバーの追加を検討する。

# 4. 減速機

減速機オイルは 12 か月ごとに交換する。磁気プラグに鉄粉が多量に付着している場合は歯面摩耗が進行しているため、減速機交換を計画する。

# 5. キャリアローラ

回転しないローラは即時交換する。固着したローラはベルト裏面の摩耗と異音の原因となる。

# 6. インバータ

過電流トリップが頻発する場合は機械側の負荷増大を先に排除したうえで、インバータの交換を行う。パラメータは制御盤内のシートに従って復元する。電気工事士の資格を要する。

# 7. 光電センサ

搬出端の位置検出が誤動作する場合はレンズ清掃と取付位置の確認を行う。改善しない場合は交換する。
